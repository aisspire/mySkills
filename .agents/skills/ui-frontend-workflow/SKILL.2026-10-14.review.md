## 优化摘要

- 保留：自包含运行、产品适配、项目技术栈与资源复用、交互状态和完整工程审查。
- 修复：中文正文、双语触发描述、元数据层级、项目约束优先级、字距与配色规则的条件化表达。
- 新增：计划自审、内容依据、模板感检查、界面文案、按任务规模分流和固定上游版本记录。
- 删除：重复的英文清单和脱离需求的固定风格枚举，收敛为内容与约束驱动的选择。
- 剩余风险：上游的审美示例会随时间变化；静态结构不能证明实际输出质量提升。

## 复审结论

- 上游文档用于提取设计建议，没有将其确认习惯、固定配色数量或字体偏好直接变成通用硬性要求。
- 用户指定的品牌、已有组件、字体和设计 token 优先；模板示例不作为风格禁令。
- 小型修复只检查受影响状态，避免强制完整设计提案或扩大改动范围。
- 原有语义、ARIA、键盘、焦点、触控、对比度、响应式、媒体尺寸、分页与虚拟化检查保留。
- 新增文案规则区分普通用户语言与技术产品术语，错误信息不推测未确认原因。
- 自包含边界保留，没有增加联网、依赖安装、提交或分发步骤。

以下仅为规则走查，未执行模型行为测试：

| 场景 | 检查结论 |
| --- | --- |
| 品牌要求 Inter 或紫色渐变 | 现有品牌规范优先，不因反模板示例改换风格 |
| 修复移动端按钮间距 | 走简化流程，检查布局、触控和焦点，无需整页设计 |
| 从零构建应用或落地页 | 先根据内容形成计划并自审，再实现和审查 |
| 用户仅要求 UI 审查 | 先输出问题与依据，不自动扩展为重设计 |
| 技术产品配置 webhook | 保留准确术语，不强制改写成普通通知设置 |
| 无截图工具 | 报告验证缺口，不宣称视觉效果已验证 |

新增流程会增加大型设计任务的计划成本，已通过局部任务分流控制范围。未发现需要额外授权才能完成本地更新的动作。当前只能宣称静态结构已校验，不能宣称完整 writing-skills 合规或生成效果已经提升。
